# User's Guide
## Online Mode (Interactive Mode）
### User Manual  
In Interactive Mode, ICBricks and the PC can establish wireless communication via low-energy Bluetooth, allowing you to control the main controller through programming.

_Note: The minimum firmware version for the main controller is V3.3.5._

### Steps
| ![](IMG/U1.gif) | ![](IMG/U2.png) |
| :---: | :---: |
| Step 1: After turning on the ICBricks main controller and opening the programming software, select "Online Mode," &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;<br/>then choose the device and Bluetooth connection method to establish the connection. | Step 2: Once the connection is successful, the block command area will automatically load the relevant ICBricks extension <br/>commands. |
| ![](IMG/U3.png) | ![](IMG/U4.png) |
| Step 3: Drag the commands into the programming area to start programming. | Step 4: After completing the programming, click the green flag to execute the program and check the execution results. |

## Download Mode
### User Manual
In Download Mode, you can download the program you've written to the main controller. The program will control the main controller according to its content.

### **Operation Steps**:  
| ![](IMG/U9.gif) | ![](IMG/U10.png) |
| :---: | :---: |
| Step 1: After turning on the ICBricks main controller and opening the programming software,<br/> select "Download Mode," then choose the device and Bluetooth connection method <br/>to establish the connection. | Step 2: Once the connection is successful, the block command area will automatically load the relevant ICBricks extension commands. |
| ![](IMG/U11.gif) | ![](IMG/U12.png) |
| Step 3: Drag the command blocks into the programming area to start programming. While dragging the command blocks, <br/>the code area will display the corresponding Lua statements for the block commands. | Step 4: After completing the programming, click the hardware control button to upload the program to the main controller and execute it. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;|
| ![](IMG/U14.gif) |  |
| Step 5: After running the program, the light in the middle of the ICBricks main controller will flash orange.<br/>Function of the Button in the Middle of the ICBricks Main Controller:<br/>+ If no program is running: Pressing this button three times in quick succession will stop the program.<br/>+ If the program is running: Pressing this button three times in quick succession will also stop the program.  | |
